# EASY TO FIT — GitHub Pages

เว็บแอปสำหรับ iPhone สไตล์ Swiss Design สีน้ำเงิน–ส้ม ใช้ฟอนต์ Prompt

## ในชุดนี้มีอะไรบ้าง

- สูตรเครื่องดื่ม 30 สูตร: คุมของว่าง 10 / เพิ่มโปรตีน 10 / เพิ่มผักผลไม้ 10
- ภาพประกอบเฉพาะสูตรครบ 30 ภาพ จัดเก็บเป็นภาพตาราง 3 ไฟล์เพื่อใช้แสดงแต่ละช่อง
- แคลอรีต่อแก้ว แคลอรีแยกส่วนผสม โปรตีน น้ำตาล และใยอาหารโดยประมาณ
- ส่วนผสม ปริมาณ วิธีทำ และคำอธิบายประโยชน์ตามส่วนผสม
- หน้า “สูตรของฉัน” แสดงเฉพาะสูตรที่ผู้ใช้กดบันทึกไว้ มีปุ่มบันทึกและนำออก
- หน้าแรกไม่แสดงจำนวนสูตร และไม่มีหน้ารวมสูตรให้เลือกเอง
- ฐานข้อมูลสูตรยังเก็บไว้เบื้องหลังเพื่อให้ระบบเลือก 2 สูตรโดยอัตโนมัติ
- แบบฟอร์มอายุ เพศ ส่วนสูง น้ำหนัก กิจกรรม และข้อจำกัดอาหาร
- หลังกรอกข้อมูล ระบบประเมิน BMI เบื้องต้นและคัด 2 สูตรทันที พร้อมเหตุผลและคำแนะนำอาหารตามวัย
- ผู้มีน้ำหนักน้อยหรืออายุ 60 ปีขึ้นไปได้รับตัวเลือกโปรตีนอย่างน้อย 1 สูตร โดยอีกสูตรยังตรงกับหัวข้อที่เลือก
- คัดสูตรที่มีนมวัวหรือถั่วเหลืองออกตามตัวเลือกที่ผู้ใช้ระบุ (ไม่ใช่ระบบตรวจการแพ้อาหารทุกชนิด)
- คูปองส่วนลดตัวอย่าง 100 บาท มีลายน้ำ “ตัวอย่าง” ใช้รับส่วนลดจริงไม่ได้
- ไม่มีระบบสมาชิกหรือฐานข้อมูลส่วนกลาง ข้อมูลฟอร์มประมวลผลในเบราว์เซอร์และหายเมื่อโหลดหน้าใหม่
- สูตรที่บันทึกเก็บเฉพาะรหัสสูตรใน localStorage ของเบราว์เซอร์ ไม่เก็บอายุ น้ำหนัก ส่วนสูง เพศ หรือผล BMI ข้ามอุปกรณ์ไม่ได้

## ขึ้น GitHub Pages แบบไม่ต้องใช้คำสั่ง

1. แตก ZIP ก่อน ไม่อัปโหลด ZIP ทั้งก้อน
2. สร้าง repository ใน GitHub เช่น `easy-to-fit`
3. เลือก Add file → Upload files
4. อัปโหลด `index.html`, `recipes.js`, `recipe-app.js`, โฟลเดอร์ `assets` และไฟล์คู่มือทั้งหมดไว้ที่ระดับแรกของ repository โดยรักษาโครงสร้างโฟลเดอร์ assets
5. กด Commit changes
6. ไป Settings → Pages
7. ใต้ Build and deployment เลือก Source เป็น Deploy from a branch
8. เลือก Branch `main` และโฟลเดอร์ `/(root)` แล้ว Save
9. เมื่อ GitHub Pages ประมวลผลเสร็จ ลิงก์เว็บจะปรากฏในหน้า Pages

สำคัญ: ต้องเห็น index.html อยู่ระดับแรก ห้ามมีโฟลเดอร์ครอบซ้อนอีกชั้น และต้องอัปโหลดโฟลเดอร์ assets ครบ

เอกสารอ้างอิง GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## เปิดใน iPhone

เปิดลิงก์ GitHub Pages ใน Safari แล้วใช้เมนูแชร์ → เพิ่มไปยังหน้าจอโฮม เพื่อสร้างทางลัด เว็บต้องโฮสต์ก่อนจึงเหมาะกับการเปิดใช้บนมือถือ

## โครงสร้างไฟล์

- index.html — โครงหน้า สไตล์ และการนำทาง
- recipes.js — ส่วนผสม ค่าโภชนาการตัวอย่าง และข้อมูล 30 สูตร
- recipe-app.js — คำนวณสารอาหาร ค้นหา กรอง และแสดงสูตร
- recommendation-core.js — ประเมิน BMI พลังงาน และจัดลำดับสองสูตร
- personalized.js — แสดงผลประเมินและสูตรที่เลือกให้
- saved-recipes.js — บันทึกและนำสูตรออกในเบราว์เซอร์
- manifest.webmanifest — ชื่อแอปและไอคอนสำหรับเพิ่มหน้าจอโฮม
- assets/ — รูปประกอบและฟอนต์ Prompt พร้อมใบอนุญาต
- RECIPE-LIST.md — รายการสูตรและแคลอรีทั้งหมด
- .nojekyll — ให้ GitHub Pages ใช้ไฟล์เว็บแบบ static

ไม่ต้องติดตั้ง npm ไม่ต้อง build และไม่ต้องใช้ API key ทุกเส้นทางไฟล์เป็น relative จึงใช้ได้กับ GitHub Pages ในโฟลเดอร์ repository

## แก้ไขสูตรและภาพ

ปรับข้อมูลใน recipes.js โดยเก็บ 10 สูตรต่อ category และให้แต่ละ id ไม่ซ้ำกัน
ปริมาณเป็นกรัม ยกเว้นน้ำ นม นมถั่วเหลือง และน้ำมะนาวที่ใช้มิลลิลิตร ค่าโภชนาการเป็นค่าประมาณต่อ 100 กรัม/มล.
รูป recipes-balance.png, recipes-protein.png และ recipes-plants.png เรียง 5 คอลัมน์ × 2 แถว ตาม index 0–9 ในแต่ละหมวด

## ขอบเขตต้นแบบ

ค่าโภชนาการเป็นข้อมูลประมาณสำหรับสาธิต ไม่ได้ตรวจรับรองเป็นรายยี่ห้อ ต้องปรับตามฉลาก/ฐานข้อมูลอาหารที่ตรวจสอบแล้วก่อนนำไปใช้ให้คำแนะนำเชิงสุขภาพจริง
สูตรทั่วไปสำหรับผู้ใหญ่อายุ 18 ปีขึ้นไป ไม่ใช่สูตรรักษาโรค และไม่รับรองผลลดน้ำหนัก เด็ก ผู้ตั้งครรภ์ ให้นมบุตร ผู้มีโรคที่ต้องควบคุมอาหาร หรือผู้มีการแพ้ซับซ้อนควรให้นักกำหนดอาหารช่วยประเมิน
อายุ เพศ ส่วนสูง น้ำหนัก และกิจกรรมใช้คำนวณพลังงานรักษาน้ำหนักโดยประมาณ ส่วนการคัดสูตรใช้เป้าหมาย ข้อจำกัดอาหาร ช่วง BMI อายุ และการจัดอันดับด้านพลังงาน โปรตีนและใยอาหาร ยังไม่ปรับปริมาณวัตถุดิบและไม่กำหนดเป้าลดน้ำหนักรายบุคคล
คูปองเป็นตัวอย่างเท่านั้น ไม่มีระบบออกสิทธิ์หรือตัดสิทธิ์จริง วันออกตัวอย่างแสดงตามวันเปิดหน้าในเขตเวลา Asia/Bangkok

## กติกาเลือกสองสูตรและขอบเขต

BMI ใช้เกณฑ์อ้างอิงผู้ใหญ่ที่ใช้ในไทย: ต่ำกว่า 18.5 น้ำหนักน้อย / 18.5 ถึงน้อยกว่า 23 อยู่ในเกณฑ์ / 23 ถึงน้อยกว่า 25 น้ำหนักเกิน / 25 ถึงน้อยกว่า 30 เข้าข่ายอ้วนระดับ 1 / ตั้งแต่ 30 เข้าข่ายอ้วนระดับ 2 เกณฑ์เดียวกันในผู้ใหญ่ชายและหญิง และจัดประเภทด้วยค่าก่อนปัดเศษ

ระบบเลือกตัวเลือกแรกจากหัวข้อที่เลือก ตัวเลือกที่สองอยู่หัวข้อเดียวกัน ยกเว้นกรณีน้ำหนักน้อย อายุ 60 ปีขึ้นไป หรือดื่มหลังออกกำลัง จะเพิ่มตัวเลือกจากกลุ่มโปรตีนหากตัวแรกยังไม่อยู่กลุ่มนั้น คัดอาหารที่หลีกเลี่ยงออกก่อน

การให้คะแนนใช้ระยะห่างจากพลังงานของว่างโดยประมาณ ร่วมกับโปรตีนและใยอาหาร จุดกึ่งกลางพลังงานในการจัดลำดับเป็นกติกาผลิตภัณฑ์ของต้นแบบ ไม่ใช่เกณฑ์คลินิก: น้ำหนักน้อยใช้ 12% ของพลังงานรักษาน้ำหนัก (จำกัด 180–300 kcal); น้ำหนักเกินในวัยต่ำกว่า 60 ใช้ 7% (จำกัด 100–180 kcal); กรณีอื่นใช้ 9% (จำกัด 140–230 kcal) ถ้าไม่ระบุเพศจะไม่แสดงพลังงานส่วนบุคคล และใช้ฐานจัดลำดับทั่วไป 1900 kcal โดยไม่แสดงเป็นค่าพลังงานของผู้ใช้

นี่เป็นเพียงการจัดลำดับสูตรอาหารทั่วไป ไม่ใช่อัลกอริทึมโภชนบำบัดที่ผ่านการตรวจรับรอง BMI ไม่แยกมวลกล้ามเนื้อ ไขมัน และกระดูก โดยเฉพาะผู้สูงอายุควรประเมินการกินและกล้ามเนื้อร่วมด้วย เลือกดื่มครั้งละ 1 สูตร ไม่ได้แนะนำให้ดื่มทั้งสองแก้วในวันเดียว

## การอัปเดตเวอร์ชันนี้

เปลี่ยนชื่อทั้งหมดเป็น EASY TO FIT ใช้ไอคอนแบบ 11 ตัวอักษร 3D ขนาดใหญ่ พื้นหลังสมูทตี้สตรอว์เบอร์รี
ขนาดไอคอนพร้อมใช้: assets/apple-touch-icon.png (180), icon-192.png, icon-512.png, easy-to-fit-icon.png (1024), favicon-32.png
หน้าแรกไม่แสดงจำนวนสูตร เมนูสูตรของฉันแสดงเฉพาะรายการที่กดบันทึกไว้ มีสถานะว่างหากยังไม่บันทึก
หน้าสรุปสองสูตรแสดงการ์ดแบบกระชับ เหตุผลและคำแนะนำอาหารเปิดอ่านเพิ่มเติมได้ รายละเอียดที่ยาวยังเลื่อนอ่านตามปกติ
เมื่ออัปโหลดไฟล์ใหม่ใน repository เดิม ให้แทนไฟล์เดิมและเพิ่ม saved-recipes.js กับ manifest.webmanifest พร้อมภาพไอคอนใหม่ทั้งหมดใน assets
บน iPhone หากมีทางลัดไอคอนเก่าอยู่แล้ว ให้ลบเฉพาะทางลัดเดิม แล้วเปิดเว็บใน Safari และเพิ่มไปยังหน้าจอโฮมใหม่ ชื่อและไอคอนจะเป็น EASY TO FIT
